三、线段相交

注意是线段相交而不是直线相交，所以既要判断a,b是不是在直线c,d两侧，也要等、判断c,d是不是在a,b两侧。同时对端点在线段上的情况单独处理。

四、多边形的面积

顶点必须按照多边形边界的顺序排列。逆时针排序得到正面积，顺时针得到负面积，所以记得加绝对值，也可以通过有向面积判断定点顺序。

七、点到直线的投影点

如果t < 0,投影点在a左侧，如果0< t < 1,投影点在ab内部，如果1 < t,投影点在b右侧。

八、点到线段的最近点

利用点到直线的投影的t的大小来做，1 < t,就是b点，t < 0,就是a点，0 < t <1,就是投影点。

九、两直线的交点

设两条非平行直线的交点为p,p=a+vt=c+sw,所以vt-sw=c-a,所以cross(vt-sw,w)=cross(c-a,w),所以t*cross(v,w)=cross(c-a,w)。

十二、射线法判断点是否在多边形内部

射线法不仅适用于凸多边形，也适用于凹多边形。多边形的顶点必须按照边界顺序依次给出，顺时针或逆时针均可。先遍历每一条边看该点是不是在边上；不在的话，以该点为起点做一条向右的射线，统计与多边形边界的交点数，偶数说明在外部，奇数说明在内部。（这里假设边界也算多边形内部，具体题目具体分析）。

关键点

可以保证直线经过某条边的下边界会统计，经过某条边的上边界不会统计，从而保证直线经过顶点的时候计数的奇偶性不变。具体而言，射线经过顶点有三种情况，
（1）局部最高点，计数0
（2）局部最低点，计数2
（3）一条边下顶点，一条边上顶点，计数1

十三、极角排序比较器

按照[0,2pi)范围进行极角排序，从 x 轴正方向开始，逆时针排序,[0,pi)为前半部分，[pi,2pi)为后半部分，在每个部分内部通过cross判断先后顺序。
其实只用cross的话，会得到a在b前，b在c前，c在a前，出现了循环，不满足 sort 的严格弱序要求。所以需要找一个分割线，我们这里以y==0为分割线,下面的极角都大于上面的。

int half(Point a) {
    if (a.y > 0) return 0;
    if (a.y == 0 && a.x >= 0) return 0;
    return 1;
}
ll norm2(Point a) {
    return a.x * a.x + a.y * a.y;
}
bool cmp(Point a, Point b) {
    if (half(a) != half(b))
        return half(a) < half(b);

    ll c = cross(a, b);

    if (c != 0)
        return c > 0;

    return norm2(a) < norm2(b);
}
