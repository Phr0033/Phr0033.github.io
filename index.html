overflow

当一个容器的内容 超出自身尺寸（宽度或高度）时，浏览器默认会显示出来，或者出现滚动条。
overflow 就用来控制这种溢出行为。

语法：

2️⃣ 常见取值
值 说明
visible 默认值。内容溢出时显示出来，不裁剪。
hidden 内容溢出部分 隐藏，不显示，也不滚动。
scroll 内容溢出时，显示滚动条（即使不溢出也显示）。
auto 内容溢出时显示滚动条，不溢出时不显示。

outline

一、outline 是什么？

outline 是 元素的轮廓线（外描边），
它看起来像边框（border），但实际上不占空间。

也就是说：

它绘制在元素边框（border）的外面；

不会影响元素的尺寸或布局；

常用于表示 元素聚焦（focus） 状态，比如 被点击时的蓝色高亮边框。

Algorithm

求最长递增系序列

const int maxn = 1e5 + 10;
int nums[maxn];
int endss[maxn];
int n;
int DP()//其实就是维护一个递减数列的最大结尾
{
	int len = 0;
	for (int i = n - 1; i >= 0; i--)
	{
		auto it = lower_bound(endss, endss + len, nums[i], greater<int>());//找到小于等于nums[i]的第一个数
		if (it == endss + len)
		{
			endss[len++] = nums[i];
			dp[i] = len;
		}
		else
		{
			int find = it - endss;
			endss[find] = nums[i];
			dp[i] = find + 1;
		}
	}
	return len;
}
lower_bound(endss, endss + len, nums[i], greater<int>())在一个 降序排列的数组 中找到第一个小于等于 nums[i] 的位置。

我的vue学习

vue是什么

  • 是一个用于构建用户界面的渐进式框架

构建用户界面

  • 基于数据动态渲染页面

框架

  • 一套完整的项目解决方案
  • 优点：提高开发效率
  • 缺点：需要理解记忆规则

Vue的两种使用方式

  • VUe核心包开发：局部模块改造
  • Vue核心包&Vue插件工程化开发：整栈开发

Vue的响应式特性

  • 响应式：数据改变，视图自动更新，使用Vue开发->专注于业务逻辑即可,只有放在data中的数据才是响应式的

vue数组的更新检测

指令修饰符

  • 案件修饰符 （只有键盘事件可用）如：keyup.enter
  • v-model修饰符 .trim .numberv
  • 事件修饰符 .stop（阻止冒泡 ） .prevent

methods里的事件处理函数

如果没有参数，默认会有一个事件对象传递过来

动态设置class

  • 设置对象：是否应用该类名
  • 设置数组：一次性设置多个类名

动态设置style

  • {css属性名：css属性值}

computed属性

  • 带缓存，但是如果数据更新了，也会重新计算

watch 属性

  • watch默认情况下只能监听基本数据类型，如果需要监听引用数据类型，必须使用完整写法开启深度侦听
